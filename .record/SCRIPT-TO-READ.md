# Portfolio Tour — Narration Script

> **Read each line once. One breath between lines. Don't rush.**

---

## How to record (2 minutes setup)

**Phone earbuds or any USB mic is fine.** The goal is "quiet room" not "studio."

1. **Find a quiet spot.** Closets work great (clothes absorb echo). Otherwise a bedroom with the door closed.
2. **Mic distance:** ~4 inches from your mouth, slightly off-axis (not directly in front).
3. **Open any voice recorder app.** Windows: Voice Recorder (built-in). Mac: Voice Memos. Phone: built-in voice memos app.
4. **Settings (if the app asks):**
   - Format: **WAV** (lossless) — if only MP3 is offered, that's fine
   - Sample rate: **48,000 Hz** (or 44,100 Hz — both work)
   - Mono (single channel)
5. **Do a 5-second test**, play it back, check the level isn't clipping (red). If it is, move the mic back an inch.
